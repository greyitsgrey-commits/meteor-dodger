# Meteor Dodger

A space dodging game made by Nathan de Waal.

**Play it:** https://greyitsgrey-commits.github.io/meteor-dodger/

## How to play

- Drag your finger, or use the arrow keys (or A and D), to move.
- Dodge the meteors.
- Grab stars to build combos, and catch glowing orbs for power-ups.
- Press M to mute the sound.

## Power-ups

| Orb | Power |
|-----|-------|
| S | Shield - rocks smash against you instead of ending the run |
| T | Slow-mo - everything falls in slow motion |
| M | Magnet - stars fly towards your ship |
| 2 | Double points |

## Shop

Stars you collect are the money. There are 216 rocket ships and 216 extras
(hats, trails, auras and buddies) to buy.

## Everything is in one file

`index.html` is the whole game - no build step, no libraries to install.
Open it in any browser and it works, even offline.
